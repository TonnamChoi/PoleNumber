# 전주번호찰의 의미 (다음 카페: 58산우회 자료)

출처: https://m.cafe.daum.net/58madang/WFPv/2472 — "전주번호찰의 의미", 58산우회

전체 맥락은 [kepco-pole-number-plate.md](./kepco-pole-number-plate.md)에 정리되어 있고,
이 문서는 해당 게시글 하나의 내용만 별도로 기록한 것이다.

## 게시글 요약

전봇대에 붙어있는 번호판(전주번호찰)의 구성과 용도를 설명하는 글.

### 전주번호찰에 담긴 정보

게시글 원문 표현: **"관리구 번호, 전산화 번호, 선로명, 현행 전주번호, 시공년월, 장척,
시공회사, 일련번호"**

### 관리구 번호의 세부 구조

- **앞의 두 자리**: 경도를 의미
- **뒤의 두 자리**: 위도를 나타냄

### 실용적 용도

긴급 상황에서 정확한 위치(건물 주소 등)를 설명하기 어려울 때 전봇대를 활용할 수 있다.
원문 표현: **"관리구번호+전산화번호 8자를 불러주면"** 정확한 위치 파악이 가능하다. 이는
119 구조 요청 시에도 유용하다.
